# 🎨 STATE 6 — Visual Style Profile

> Source: sample frames from **Bob Invests** videos (as shown in the tutorial video).
> This style is used for EVERY image prompt in State 7 — never deviate.

## The profile

| Element | Value |
|---|---|
| **Art style** | Flat vector illustration, clean shapes, slight 3D shading, no photo-realism |
| **Color palette** | Warm amber/gold + deep navy + cream; accent green for money, red for costs/danger |
| **Lighting** | Soft cinematic key light from upper-left, gentle rim light, warm glow |
| **Camera style** | Wide establishing shots + medium close-ups on faces/objects; slight low angle for drama |
| **Composition** | Subject off-center with negative space for captions; strong foreground/background depth |
| **Detail level** | Clean minimal detail — readable at 480p, no clutter |
| **Mood** | Calm, warm, slightly cinematic; dramatic but never scary |

## Fixed elements (apply to EVERY prompt)

- **Dust particles** floating in the air (signature of the channel)
- **Subtitles at bottom-center** (added in edit, not in the image)
- **Slow zoom in/out** (added in edit)
- **16:9** landscape, 1920×1080
- Style tag to append: `flat vector illustration, warm amber and deep navy color palette, cream background, soft cinematic lighting, gentle rim light, floating dust particles, subtle film grain, 16:9 widescreen, clean minimal detail`

## Avatar rule

- Dedicated avatar in **opening scene only** (a generic narrator silhouette/character), NOT narrating on-screen in other scenes — voiceover-only + illustrated scenes, matching the reference channel.
